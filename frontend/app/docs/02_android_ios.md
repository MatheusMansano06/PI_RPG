# Android e iOS

O projeto mobile ficou separado assim:

- `android/`: configuracao nativa Android, Gradle e chave do Google Maps.
- `ios/`: configuracao nativa iOS, Xcode, Info.plist e chave do Google Maps.
- `lib/`: codigo Flutter compartilhado pelos dois sistemas.
- `assets/`: imagens e audios usados nos dois sistemas.

Pastas de desktop e web foram retiradas para nao misturar a entrega mobile.
